# Gridorastudio

Create Gridora Studio as a professional graphic design editor inspired by PixelLab.

IMPORTANT: Do not include templates or template galleries anywhere in the entire website.

Do not display:
- Ready-made design templates.
- Template galleries or template recommendations.
- Pre-designed flyers, posters, or social media designs.
- A template marketplace.
- Suggested designs on the dashboard.

NEW DASHBOARD

Create a clean dashboard featuring:
- Gridora Studio logo and branding.
- A prominent "Create New Design" button.
- Recently edited projects.
- My Designs section.
- Custom canvas size options / presets.
- A simple, professional interface.

BLANK CANVAS

When users click "Create New Design", open a completely blank canvas.
Allow users to choose their canvas dimensions, background color, or transparent background before starting.

DESIGN TOOLS

Provide a fully functional graphic design editor with:
- Add and edit text.
- Font selection and font size.
- Bold, italic, and text alignment.
- Text colors, gradients, outlines, and shadows.
- Text rotation and letter/line spacing.
- Image uploads.
- Image cropping, resizing, and rotation.
- Shapes, stickers, and icons.
- Background colors and gradients.
- Object layers and layer ordering (bring forward, send backward, lock, hide).
- Undo and redo.
- Duplicate and delete.
- Zoom controls and canvas pan.
- Custom canvas dimensions.
- PNG, JPG, and transparent PNG export.
- PDF export where supported.

DESIGN WORKFLOW

Users must create every design from scratch using the available tools.
Do not automatically place text, images, shapes, or other design elements on a new canvas.
Do not show templates anywhere in the application.
Keep the dashboard focused on creating new designs and accessing previously saved projects.
Ensure all buttons and editing features work correctly.
Make the interface responsive and easy to use on both mobile phones and desktop computers.

The final result should be a blank-canvas graphic design application similar in workflow to PixelLab, with powerful typography, image editing, layers, and export tools.
